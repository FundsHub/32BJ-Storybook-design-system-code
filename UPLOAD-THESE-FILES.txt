32BJ Storybook V1.3.2 CI + GitHub Pages Patch

This patch adds automated validation and Storybook publishing.

FILES
1. package.json
2. DEPLOYMENT.md
3. .github/workflows/storybook-pages.yml

IMPORTANT
The workflow file MUST be located at:
.github/workflows/storybook-pages.yml

Do not place storybook-pages.yml in the repository root.

After upload, open GitHub:
Settings > Pages > Build and deployment
Set Source to GitHub Actions.

Then open the Actions tab and watch the Storybook CI and Pages workflow.
